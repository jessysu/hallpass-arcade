# Hallpass Arcade

A one-file browser game site with 14 original games. No downloads, no sign-ups; best scores are saved in your browser.

**Play:** open `index.html` in any modern browser, or visit the GitHub Pages site for this repository.

## Games

| Type | Games |
|---|---|
| Arcade | Coil, Shatter, Hop Dash, Orbit |
| Skill | Pop |
| Puzzle | Minefield, Pairs, Three in a Row |
| Space | Void Raiders, Hive Siege, Gravity Duel (1 or 2 players) |
| Tanks | Tank Arena, Team Siege, Tank Overdrive |

**Tank Overdrive** is the big one: four modes (free for all, 2 teams, 4 teams, boss fight), 94 starting tanks plus five
XP-unlocked tiers of upgrades, a Q power and a passive on every tank, 15 bosses, permanent-buff relics and other
special entities.

## Controls

Each game lists its controls under the play area. Most use the keyboard and mouse, and also work with touch.

## Development

Everything is in `index.html`: plain HTML, CSS and JavaScript, with no build step and no libraries. Fonts load from
Google Fonts. To work on it, edit the file and reload the page.
